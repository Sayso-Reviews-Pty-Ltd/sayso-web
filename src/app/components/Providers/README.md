# Providers

App-level React context providers and performance wrappers.

## Files

| File                         | Description                                         |
| ---------------------------- | --------------------------------------------------- |
| `DeferredProviders.tsx`      | Mounts non-critical providers after first paint     |
| `PageTransitionProvider.tsx` | Provides page transition state to children          |
| `SWRProvider.tsx`            | Wraps the app with `SWRConfig` global configuration |

## Used By

Root layout.
