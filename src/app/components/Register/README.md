# Register

Registration form components for the user sign-up page.

## Files

| File                    | Description                           |
| ----------------------- | ------------------------------------- |
| `RegisterForm.tsx`      | Main registration form                |
| `ConsentCheckbox.tsx`   | Terms & privacy consent checkbox      |
| `ErrorMessage.tsx`      | Inline field error display            |
| `FormField.tsx`         | Register-specific form field wrapper  |
| `PasswordStrength.tsx`  | Password strength bar                 |
| `ProgressIndicator.tsx` | Multi-step registration progress      |
| `SubmitButton.tsx`      | Form submit button with loading state |
| `ValidationMessage.tsx` | Validation hint messages              |

## Used By

`/register` page.
