# BusinessDetail

Full business detail page components — header, info cards, map, events section, and gallery.

## Files

| File                             | Description                                       |
| -------------------------------- | ------------------------------------------------- |
| `BusinessDetailHeader.tsx`       | Hero header with image, name, and primary actions |
| `BusinessHeroImage.tsx`          | Optimised hero image with blur placeholder        |
| `BusinessActionCard.tsx`         | CTA card (save, share, write review, claim)       |
| `BusinessContactCard.tsx`        | Phone/email/website contact strip                 |
| `BusinessContactInfo.tsx`        | Contact info row items                            |
| `BusinessDescription.tsx`        | Collapsible business description                  |
| `BusinessDetailsCard.tsx`        | Hours, category, amenities card                   |
| `BusinessInfo.tsx`               | Quick-info bar (rating, reviews, distance)        |
| `BusinessLocation.tsx`           | Address with map link                             |
| `BusinessOwnedEventsSection.tsx` | Events & specials section on the business page    |
| `BusinessPhotoGrid.tsx`          | Photo gallery grid                                |
| `AddressPill.tsx`                | Compact address chip                              |
| `MapboxMap.tsx`                  | Embedded Mapbox map                               |
| `PercentileChipsSection.tsx`     | Rating percentile chips                           |
| `PersonalizationInsights.tsx`    | Personalised "why you'll love this" section       |
| `hooks/`                         | Business detail data hooks                        |
| `index.ts`                       | Barrel exports                                    |

## Used By

`/business/[id]` page.
