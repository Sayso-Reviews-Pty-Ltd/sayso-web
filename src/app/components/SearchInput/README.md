# SearchInput

Full-featured search input with live suggestions, recent history, and category filters.

## Files

| File              | Description                                    |
| ----------------- | ---------------------------------------------- |
| `SearchInput.tsx` | Main search input with dropdown                |
| `hooks/`          | `useSearchHistory`, `useSuggestions`, etc.     |
| `parts/`          | Suggestion list, recent searches, filter chips |

## Dependencies

- **Hooks:** `useLiveSearch`, `useSearchSuggestions`

## Used By

Header search, `/search` page.
