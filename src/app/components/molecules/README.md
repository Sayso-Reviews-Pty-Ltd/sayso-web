# Molecules

Mid-level components composed from atoms — they carry UI logic but no data fetching.

## Subdirectories

| Directory                 | Description                                                     |
| ------------------------- | --------------------------------------------------------------- |
| `AchievementItem/`        | Single badge/achievement row with icon, name, and earn date     |
| `Card/`                   | Generic card container with glass/premium/bordered variants     |
| `ConfirmationDialog/`     | Accessible alert dialog for destructive confirmations           |
| `DangerAction/`           | Warning row with title, description, and danger CTA button      |
| `FormField/`              | Input with label, required indicator, and description           |
| `NotificationToggleItem/` | Label + description + toggle for notification preferences       |
| `ProfileHeader/`          | Avatar, display name, username, and optional top-reviewer badge |
| `ProfileInfoItem/`        | Label + value row with optional coloured icon                   |
| `ReviewItem/`             | Review card with business thumb, rating, text, and actions      |
| `SearchBar/`              | Controlled search input with clear button                       |
| `SettingsHeader/`         | Fixed top header with back link for settings pages              |
| `SettingsMenuItem/`       | Settings list row with icon, label, and optional chevron        |
| `StatsGrid/`              | Responsive grid of `StatCard` tiles                             |
| `UserCard/`               | Avatar + name + username + optional bio and badge               |
