# HomeSectionRow

Titled horizontal card rail section used throughout the home and feed pages.

## Files

| File                   | Description                                                 |
| ---------------------- | ----------------------------------------------------------- |
| `HomeSectionRow.tsx`   | Section with title, optional "See all" link, and `CardRail` |
| `cardDimensions.ts`    | Card width/height constants for rail layout calculations    |
| `homeSectionLayout.ts` | Layout config (spacing, gutters) for section rows           |

## Used By

Home page, for-you feed, trending section.
