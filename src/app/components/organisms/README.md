# Organisms

Large section-level components used in settings and profile pages. Composed from molecules and atoms.

## Subdirectories

| Directory                 | Description                                          |
| ------------------------- | ---------------------------------------------------- |
| `AchievementsList/`       | Titled list of achievement items                     |
| `DangerZoneSection/`      | Deactivate and delete account actions                |
| `DataRightsSection/`      | GDPR/POPIA data rights (export, deletion requests)   |
| `NotificationCategory/`   | Grouped notification toggle rows                     |
| `NotificationsSection/`   | Notification settings card                           |
| `PasswordChangeForm/`     | Current + new + confirm password change form         |
| `PrivacySettingsSection/` | Privacy preference toggles                           |
| `ProfileSettingsSection/` | Display name, username, bio edit form                |
| `ProfileStatsSection/`    | Stats grid (reviews, helpful votes, etc.)            |
| `ReviewsList/`            | Collapsible list of `ReviewItem` cards               |
| `SecurityPrivacySection/` | Two-factor auth and session management               |
| `SettingsMenu/`           | List of `SettingsMenuItem` rows grouped with a title |
