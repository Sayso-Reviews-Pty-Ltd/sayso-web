# Explore

Explore hub components — area explorer, category grid, collections, and intent browser.

## Files

| File                       | Description                            |
| -------------------------- | -------------------------------------- |
| `AreaExplorer.tsx`         | Browse businesses by geographic area   |
| `CategoryGrid.tsx`         | Grid of category cards                 |
| `Collections.tsx`          | Curated collections grid               |
| `ExploreHeader.tsx`        | Page header with search                |
| `IntentBrowser.tsx`        | Browse by user intent ("I want to...") |
| `BusinessGridSkeleton.tsx` | Loading skeleton                       |

## Used By

`/explore` and sub-routes (`/explore/area/[id]`, `/explore/category/[id]`, etc.).
