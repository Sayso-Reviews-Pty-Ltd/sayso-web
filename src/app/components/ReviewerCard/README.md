# ReviewerCard

Reviewer profile card with avatar, stats, and recent reviews.

## Files

| File                          | Description                               |
| ----------------------------- | ----------------------------------------- |
| `ReviewerCard.tsx`            | Main reviewer card                        |
| `ProfilePicture.tsx`          | Reviewer avatar with badge overlay        |
| `ReviewContent.tsx`           | Recent review snippets                    |
| `ReviewerCardSkeleton.tsx`    | Loading skeleton                          |
| `ReviewerProfileSkeleton.tsx` | Full profile page skeleton                |
| `ReviewerStats.tsx`           | Review count, helpful votes, streak stats |

## Used By

`/reviewer/[id]` page, top reviewers section.
