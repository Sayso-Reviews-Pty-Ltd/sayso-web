Generic loading skeleton primitives.

| File                 | Description                 |
| -------------------- | --------------------------- |

| `SkeletonButton.tsx` | Button-shaped skeleton      |
| `SkeletonCard.tsx`   | Card-shaped skeleton        |
| `SkeletonHeader.tsx` | Page header skeleton        |
| `SkeletonList.tsx`   | List of skeleton rows       |
