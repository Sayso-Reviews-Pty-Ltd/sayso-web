# shared/skeletons

Named skeleton templates that mirror specific page layouts during loading.

## Files

| File                 | Description         |
| -------------------- | ------------------- |
| `Skeleton.tsx`       | Base skeleton block |
| `SkeletonButton.tsx` | Button placeholder  |
| `SkeletonCard.tsx`   | Card placeholder    |
| `SkeletonHeader.tsx` | Header placeholder  |
| `SkeletonList.tsx`   | List placeholder    |

## Used By

Suspense boundaries and SWR loading states across page routes.
