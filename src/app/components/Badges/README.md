# Badges

Badge display components for user profiles and the badge achievement system.

## Files

| File                     | Description                                                 |
| ------------------------ | ----------------------------------------------------------- |
| `BadgeCard.tsx`          | Full badge card with icon, name, description, and earn date |
| `BadgeGrid.tsx`          | Responsive grid of badge cards                              |
| `BadgeModal.tsx`         | Modal showing badge details on click                        |
| `BadgePill.tsx`          | Compact inline badge pill                                   |
| `NextBadgeNudge.tsx`     | Nudge banner showing progress toward the next badge         |
| `ProfileBadgeRibbon.tsx` | Horizontal ribbon of earned badge icons on a profile        |

## Used By

`/badges` page, user profile page, review submission success screen.
