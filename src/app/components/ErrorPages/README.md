# ErrorPages

Reusable error page template for 404, 500, and other error states.

## Files

| File            | Description                                        |
| --------------- | -------------------------------------------------- |
| `ErrorPage.tsx` | Error page with icon, title, message, and back CTA |
| `index.ts`      | Barrel re-export                                   |

## Used By

`not-found.tsx`, `error.tsx`, and empty-state screens.
