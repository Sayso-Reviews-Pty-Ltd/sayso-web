# Hero

Home page hero section with carousel, skeleton, and scroll-triggered animations.

## Files

| File                     | Description                                         |
| ------------------------ | --------------------------------------------------- |
| `HeroCarousel.tsx`       | Auto-playing carousel of featured businesses/events |
| `HeroFallback.tsx`       | Static fallback if carousel data is unavailable     |
| `HeroSkeleton.tsx`       | Desktop loading skeleton                            |
| `MobileHeroSkeleton.tsx` | Mobile loading skeleton                             |
| `hooks/`                 | Hero data and animation hooks                       |
| `index.ts`               | Barrel re-export                                    |

## Used By

Home page.
