# Animations

Collection of Framer Motion animation primitives for scroll reveal, stagger, fade, and interactive effects.

## Files

| File                     | Description                                                |
| ------------------------ | ---------------------------------------------------------- |
| `AnimatedElement.tsx`    | Generic animated wrapper for any element                   |
| `DynamicAnimations.tsx`  | Dynamically loaded animation variants                      |
| `FadeInUp.tsx`           | Simple fade-in-from-below entrance                         |
| `FloatingElements.tsx`   | Floating orb/particle background elements                  |
| `FloatingElements.css`   | Keyframe CSS for floating animation                        |
| `MagneticButton.tsx`     | Button with magnetic cursor-following effect               |
| `OptimizedFadeInUp.tsx`  | Performance-optimised fade-in-up (skips on reduced motion) |
| `PageLoad.tsx`           | Full-page entrance animation on route change               |
| `PremiumHover.tsx`       | Subtle lift-and-glow hover effect                          |
| `ScrollReveal.tsx`       | IntersectionObserver-based scroll reveal wrapper           |
| `StaggerContainer.tsx`   | Stagger animation container                                |
| `StaggeredContainer.tsx` | Alternative stagger container variant                      |
| `WavyScrollTitle.tsx`    | Wavy text animation triggered on scroll                    |
| `WavyTypedTitle.tsx`     | Typed + wavy heading animation                             |
| `useScrollReveal.tsx`    | Hook variant of scroll reveal                              |
| `index.ts`               | Barrel exports                                             |

## Used By

Hero section, home page headers, and decorative page elements.
