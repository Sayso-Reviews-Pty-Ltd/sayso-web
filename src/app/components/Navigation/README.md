# Navigation

Utility navigation components for breadcrumbs, links, and scroll-to-top.

## Files

| File                      | Description                                    |
| ------------------------- | ---------------------------------------------- |
| `BreadcrumbTitleSync.tsx` | Syncs the page `<title>` with breadcrumb state |
| `OptimizedLink.tsx`       | `next/link` wrapper with prefetch optimisation |
| `ScrollToTopButton.tsx`   | Floating "scroll to top" button                |

## Used By

Page layouts, long-form content pages.
